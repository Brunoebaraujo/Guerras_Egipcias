🎨 Gerador de Arte - Guerras Egípcias

📋 Instruções:

  1. Clique em "Gerar Arte" para cada carta (leva ~30-60 segundos)
  2. Verifique a preview e aprove a imagem
  3. Clique "Baixar WebP" para salvar em 1000×1000
  4. Mova os arquivos para: public/cartas/[nome].webp
  5. Execute: npm run assets:resolucoes
  6. Commit e push!
